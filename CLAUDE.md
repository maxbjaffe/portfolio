# maxjaffe.ai Portfolio

## What This Is
Personal portfolio website showcasing AI/automation projects. Target audience: potential employers and collaborators.

## Tech Stack
- **Frontend:** Static HTML/CSS/JS
- **Hosting:** Vercel
- **Domain:** maxjaffe.ai

## Key Files
```
index.html            # Main page
images/               # Project screenshots and assets
vercel.json           # Vercel config
```

## Content Focus
- GiftStash (SMS gift tracking)
- Study Buddy (AI flashcard generator)
- Morning Rundown (daily briefings)
- Jarvis (voice assistant - planned)
- Home automation projects

## Common Tasks

### Run locally
Just open index.html in browser, or:
```bash
npx serve .
```

### Deploy
Push to GitHub → Vercel auto-deploys to maxjaffe.ai
